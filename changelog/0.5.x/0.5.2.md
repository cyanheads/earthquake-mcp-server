# 0.5.2 — 2026-11-13

## Added

- **Focal mechanisms** — Use a complete nodal-plane pair from another tensor or a focal-mechanism product when the preferred tensor lacks one. `nodal_planes_from` identifies the selected product. Preferred tensor metadata also includes magnitude, magnitude type, double-couple fraction, and source when published. ([#76](https://github.com/cyanheads/earthquake-mcp-server/issues/76))

## Changed

- **Earthquake guide 1.2** — Document the ShakeMap units, focal-mechanism provenance, PAGER region codes, and EMSC magnitude-type matching.
- **Framework tooling** — Sync developer checks, MCPB cleanup, release scripts, and framework skills.

## Fixed

- **Event text and links** — Preserve literal upstream punctuation and line breaks in event, search, feed, and PAGER text. Keep published URL destinations intact and render populated event type and certainty. ([#68](https://github.com/cyanheads/earthquake-mcp-server/issues/68))
- **Resource cancellation test** — Cancel once the fake upstream receives the request so the test deterministically verifies that cancellation stops retries. ([#70](https://github.com/cyanheads/earthquake-mcp-server/issues/70))
- **ShakeMap PGV** — Convert early 4.0 builds that publish natural-log PGV to cm/s. ([#71](https://github.com/cyanheads/earthquake-mcp-server/issues/71))
- **ShakeMap PGA** — Convert recognized legacy percent-g values and early 4.0 natural-log values to g. ([#72](https://github.com/cyanheads/earthquake-mcp-server/issues/72))
- **PAGER exposure** — Explain `XF`, `EU`, `WU`, and `UK` in the schema and label matching rows while preserving the published codes, counts, and order. ([#73](https://github.com/cyanheads/earthquake-mcp-server/issues/73))
- **EMSC magnitude filters** — Suggest a lowercase retry on an empty first search page or zero count when the filter contains uppercase characters. Send and echo the requested spelling unchanged. ([#74](https://github.com/cyanheads/earthquake-mcp-server/issues/74))
- **Epicenter coordinates** — Render latitude and longitude at the precision of the structured values. ([#75](https://github.com/cyanheads/earthquake-mcp-server/issues/75))
