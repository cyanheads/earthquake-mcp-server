# 0.3.3 — 2026-08-18

## Fixed

- **`max_pga`** relabeled from "percent of g" to `g`, the fraction-of-standard-gravity unit USGS's own ShakeMap `info.json` declares; the numeric value is unchanged ([#30](https://github.com/cyanheads/earthquake-mcp-server/issues/30)).
- **EMSC `event_type`** decoded from its two-character code to the same QuakeML vocabulary USGS publishes, so an ordinary EMSC earthquake no longer renders `Event type: ke` in `content[]`. A new `event_certainty` field (`known`/`suspected`/`unknown`/`unreported`) carries the code's certainty axis; a code outside the published nomenclature forwards verbatim rather than dropping or misclassifying ([#35](https://github.com/cyanheads/earthquake-mcp-server/issues/35)).
- **`earthquake_search`** discloses a failed total-count sub-call via `countUnavailable: true` on both `structuredContent` and `content[]`, with a distinct notice, instead of looking identical to a normal capped page ([#36](https://github.com/cyanheads/earthquake-mcp-server/issues/36)).
- Output schema and README corrected: EMSC's `ue` code documented as "unknown certainty + earthquake," not "unknown event"; `earthquake_search`'s tool description no longer claims `totalCount` always carries the full match count on a capped page.
