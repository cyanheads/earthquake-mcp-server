# 0.3.5 — 2026-09-13

## Changed

- **A non-retryable upstream failure stays non-retryable** — `earthquake_search`, `earthquake_count`, `earthquake_get_feed`, `earthquake_get_event`, and `earthquake://event/{event_id}` carry an upstream `retryable: false` into their declared `source_unavailable` / `feed_unavailable` failure, with a recovery hint naming the other catalog and the upstream error attached as `cause`. A 501 is no longer retried.
- **An upstream 500 retries** instead of failing on the first attempt — it classifies as `ServiceUnavailable` rather than `InternalError`, which put it outside the transient set.
- **An argument rejection returns the structured error envelope** in both `structuredContent` and `content[]`, classified `InvalidParams` (-32602); the readable `Invalid arguments for tool <name>: …` text is unchanged.
- **A caller that disconnects mid-call classifies as `RequestCancelled` (-32011)**, not `InternalError`.
- **`USGS_BASE_URL`, `EMSC_BASE_URL`, `DEFAULT_LIMIT`, and `REQUEST_TIMEOUT_MS` read an empty string and a whole-value `${…}` placeholder as unset** and take their defaults. A URL that merely contains `${…}` is kept; a nonblank malformed value still fails by variable name.
- **Bun engines floor raised to `>=1.4.0`** — an install on Bun 1.3 no longer satisfies the range. The Docker images already pin 1.4.0.
- **`MCP_RESPONSE_VERBOSITY` and the `OAUTH_PROXY_*` block are no longer recognized** — drop them from any deployment environment that still sets them.
- **Framework skills moved from `skills/` to `framework-skills/`** — plugin hosts auto-load a root `skills/`, so installing this server as a Claude Code or Codex plugin handed its development skills to the installing agent.
- **`bun run audit:fix` runs `bun audit fix`**, and `changelog/` ships in the npm package so the per-version entries are readable from an install.
- Plugin and bundle manifests carry the author contact and keywords `lint:packaging` checks; the bug-report form routes vulnerabilities to a private advisory.

## Fixed

- **A trailing slash on `MCP_PUBLIC_URL` no longer doubles** in the URLs the landing page and `/.well-known/mcp.json` emit.
- **The landing page's curl snippet sends a handshake `initialize` accepts** — it pinned a protocol revision behind an `MCP-Protocol-Version` header.
- **A cancelled single-request POST closes its SSE stream immediately** rather than holding it open to keep-alive or session expiry.
