# 0.3.4 — 2026-08-25

## Added

- **Cache hints** on `tools/list`, `resources/list`, `resources/templates/list`, `server/discover` (1h, public — the four tools' inventory is fixed at build time) and the `earthquake://feed/{magnitude_tier}` resource (1m, public — matches USGS's feed regeneration interval). Only a 2026-07-28 client reads them.

## Changed

- **Tool inputs are strict at the root** — an argument key a tool's schema doesn't declare is now rejected by name (`unrecognized_keys`) instead of silently stripped. Previously a typo'd filter (e.g. `min_magnitud`) parsed clean and was dropped, so a caller got unfiltered results with no signal.
- Advertised `inputSchema`/`outputSchema` moved to JSON Schema 2020-12; `outputSchema` now declares the error envelope alongside the success shape.
- Every HTTP endpoint now serves protocol revision 2026-07-28 alongside the 2025 era.
- `MCP_SESSION_MODE` documented as `stateless` — the mode this server's Docker image and `.env.example` ship — alongside new `MCP_HTTP_RESUMABILITY*` and `MCP_LOG_RATE_LIMIT_*` env vars.
- `@cyanheads/mcp-ts-core` `^0.11.5` → `^0.12.3` — the MCP SDK dependency splits into `@modelcontextprotocol/client` + `@modelcontextprotocol/server` `^2.0.0`, replacing the single `@modelcontextprotocol/sdk` `^1.30.0` package. `@biomejs/biome` `^2.5.8` → `^2.5.10`, `tsc-alias` `^1.9.1` → `^1.9.2`, `vitest` `^4.1.10` → `^4.1.11`.
- Docker images pin Bun `1.4.0`; the build stage now runs under `--platform=$BUILDPLATFORM` so the `linux/amd64` leg of the multi-arch build no longer compiles under QEMU, where Bun 1.4 aborts.
- Synced `skills/` and the lint scripts to mcp-ts-core 0.12.3.
