# 0.3.7 — 2026-09-26

## Changed

- **Input recovery** through the framework now repairs safe integers sent for string fields, including `event_id`. Rejected calls name the affected field and correction, such as sending `event_id` as a string or `limit` as an integer.
- **HTTP protocol validation** through MCP SDK 2.1.0 rejects a 2026-07-28 POST missing `MCP-Protocol-Version` with HTTP 400 / `-32020`; clients must send the negotiated protocol header.
- **Docker installs** now carry the existing three-day release-age guard and Socket scanner into production installs. OTLP peers, including log exporters, use the installed framework's tested ranges; the unused `MCP_FORCE_CONSOLE_LOGGING` setting is removed.
- **Logging configuration** documents opt-in OTLP logs through `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT` and failed-call payloads through `LOG_TOOL_FAILURE_PAYLOADS`, capped by `LOG_TOOL_FAILURE_PAYLOAD_MAX_BYTES`. Payload redaction matches key names; secrets inside free-form values remain.
- **Packaging** excludes built `.mcpb` archives from npm and local logs and idea notes from desktop bundles. The bundle author retains `cyanheads` and drops the email and URL fields.
- **Release tooling and guidance** sync with the framework: definition import failures and malformed registry metadata fail lint, packaging checks manifest versions and Docker build platforms, and GitHub release publishing validates tag annotations first.
- **Documentation** condenses the capability reference, clarifies that explicit session `auto` resolves to stateful, and corrects `LOGS_DIR` to include Bun's Node-compatible logging. The declared server default remains stateless.

## Dependencies

- **`@cyanheads/mcp-ts-core`** ^0.13.6 → ^0.13.9. Framework error data omits internal stacks and request context; output-contract failures use `InternalError`; `TimeoutError` deadlines classify as `Timeout`; diagnostics and error counters follow their corrected destinations and classifications.
- **OpenTelemetry behavior** from the framework honors `OTEL_EXPORTER_OTLP_ENDPOINT` for traces and metrics. Log export requires its separate endpoint; debug logging reaches stderr, and an unwritable file sink no longer prevents startup.
- **`@socketsecurity/bun-security-scanner`** ^1.1.2 → ^1.1.3.
- **`@types/node`** ^26.6.1 → ^26.6.2.
- **`ignore`** ^7.0.9 → ^7.0.10.
- **Bun** 1.4.0 → 1.4.2 in the package-manager pin, Docker images, and README badge.
