# 0.3.8 — 2026-10-10

## Changed

- **Tool errors** carry correlated request IDs through mcp-ts-core 0.13.10, generated independently of JSON-RPC IDs since 0.13.12.
- **Docker builds** install production dependencies in a platform-native stage, cross-install OTel peers at the framework's ranges, and prune musl-only bindings from the glibc image.
- **Registry launch metadata** uses `npx` without npm-script arguments; the HTTP entry fixes `MCP_TRANSPORT_TYPE=http`.
- **Maintenance checks and guidance** sync framework scripts, skills, environment references, and per-language CodeQL categories. Bundle exclusions cover root caches, logs, coverage, tests, source, scripts, and docs; ignore rules cover environment files and registry credentials.

## Fixed

- **Feed/search `limit`** numeric strings and optional `cursor`/`max_magnitude` nulls are repaired by mcp-ts-core 0.13.14. Limits retain their existing bounds.
