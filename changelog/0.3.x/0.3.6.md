# 0.3.6 — 2026-09-19

## Changed

- **A case or separator variant of a declared parameter name now resolves to that parameter** — `minMagnitude` reaches the handler as `min_magnitude` — while a genuinely unknown key is still rejected by name. The advertised `inputSchema` is unchanged.
- **Tool error text now closes with the reason and retryability a caller branches on** — `(reason source_unavailable · retryable)` — and an argument rejection carries a `Recovery:` line and `data.reason: "invalid_arguments"`.
- **`src/index.ts` now declares `sessionMode: 'stateless'` on `createApp()`** — the Docker image and `.env.example` already set `stateless`, so hosted and documented behavior is unchanged, but a deployment that sets no `MCP_SESSION_MODE` at all now runs stateless instead of resolving the schema default `auto` to `stateful`. An explicit `MCP_SESSION_MODE` still overrides the declaration.

## Security

- **Five polynomial-time regexes rewritten to linear time**, two of them on client-supplied input.
