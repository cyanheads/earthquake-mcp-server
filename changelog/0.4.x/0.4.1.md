# 0.4.1 — 2026-10-24

## Added

- **Search/count filters** accept `magnitude_type` on both sources and USGS-only `product_type` and `review_status`; EMSC discloses unsupported filters in `ignoredFilters`. Blank values mean omitted. ([#55](https://github.com/cyanheads/earthquake-mcp-server/issues/55))
- **ShakeMap `code_version`** exposes the producer version on event tool and resource responses when published.

## Changed

- **Advertised catalog** trims repeated schema prose while preserving units, uncertainty, source differences, and recovery guidance; the complete `tools/list` response decreases from 53,325 to 46,926 bytes. ([#56](https://github.com/cyanheads/earthquake-mcp-server/issues/56))
- **Analysis-product guidance** describes absent projected fields without implying zero impact or proving no upstream product was produced.

## Fixed

- **Event identity** trims and rejects blank IDs before fetching, accepts canonical IDs and aliases case-insensitively, and reports collections, empty responses, and mismatched features as `not_found`. Event resource parameters decode once before validation. ([#47](https://github.com/cyanheads/earthquake-mcp-server/issues/47))
- **Deleted USGS events** return non-retryable `event_deleted` with replacement-search guidance on tool and resource surfaces, without forwarding the captured response body. ([#48](https://github.com/cyanheads/earthquake-mcp-server/issues/48))
- **Inverted query ranges** fail locally as `invalid_range` for magnitude, depth, and explicit time pairs; equal or single bounds remain valid, and timestamps compare as UTC instants. ([#49](https://github.com/cyanheads/earthquake-mcp-server/issues/49))
- **EMSC rejection messages** decode JSON `detail` envelopes before extracting the diagnostic, omitting echoed requests and service boilerplate. ([#50](https://github.com/cyanheads/earthquake-mcp-server/issues/50))
- **Historical ShakeMap PGV** converts logarithmic maxima to cm/s only for producer `4.0.2+335.gcbad862` and its `.dirty` variant; other producer versions retain their published values. ([#51](https://github.com/cyanheads/earthquake-mcp-server/issues/51))
- **Search totals** survive byte shaping when a short upstream page establishes the total; empty first pages report zero, and empty later pages leave the total unknown. Count guidance treats 20,000 as a single-request threshold and supports offset paging beyond it. ([#52](https://github.com/cyanheads/earthquake-mcp-server/issues/52))
