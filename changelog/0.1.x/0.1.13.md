# 0.1.13 — 2026-06-12

## Added

- **`createApp()` identity** — explicit `name` and `title` set to `earthquake-mcp-server`, so the hyphenated repo name is the displayed identity rather than the npm-scoped package name.
- **`scripts/clean-mcpb.ts`** — post-pack MCPB cleaner wired into `bun run bundle`: runs `mcpb clean` (dev-dependency prune) then strips dependency-shipped agent docs (`node_modules/**` `skills/`, `.claude/`, `.agents/`, `SKILL.md`) that root-anchored `.mcpbignore` patterns cannot reach.
- **`lint-packaging` bundle-content guards** — new checks reject unanchored `.mcpbignore` patterns and patterns stripping critical runtime paths, and assert a built `dist/*.mcpb` ships zero `node_modules/**` agent-doc entries. `AGENT_DOC_ENTRY` is kept in sync with `clean-mcpb.ts`.
- **`check-framework-antipatterns` rule 4** — flags `z.coerce.boolean()` on env flags (`Boolean("false")` is `true`, so the flag can't be disabled via env); recommends `z.stringbool()`. Comment lines are skipped so doc mentions don't false-positive.
- **Dockerfile `HEALTHCHECK`** — bun-native `fetch` against `/healthz` (the slim image ships no curl/wget); `org.opencontainers.image.version` label populated from an `APP_VERSION` build arg.

## Changed

- **`.mcpbignore`** — patterns root-anchored with a leading `/`; added `/.agents/` and `/skills/`.
- **`techniques` skill** — added to the vendored skill set; synced all project skills to `@cyanheads/mcp-ts-core` `^0.10.6`.

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.9.21 → ^0.10.6
- `@types/node` ^25.9.1 → ^25.9.3
