# 0.1.15 — 2026-06-20

## Changed

- **`@cyanheads/mcp-ts-core` `^0.10.6` → `^0.10.9`** — picks up: a `check-dependency-specifiers` devcheck step that rejects floating specifiers (`latest`, `*`, pre-release dist-tags) in `package.json` and `bun.lock` workspaces before a stray `latest` in the lock can re-resolve a dep past its range; plugin-marketplace manifest validation in `lint:packaging` (display fields carry the unscoped name, install args the full scoped name); fresh-scaffold guards so the git-dependent and changelog-sync devcheck steps skip cleanly when `.git` is absent; the `DuckdbProvider.describe({ tableName })` ambiguous-column fix; biome `2.4.16` → `2.5.0`; and `ctx.content` — an always-present collector for image/audio content blocks that ride `content[]` only, never `structuredContent`.
- **`devcheck.config.json`** — added `packaging.pluginManifests: true`, enabling the new plugin-marketplace checks against `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json`.
- **Agent skills + devcheck scripts re-synced** to the `^0.10.9` framework: 14 `skills/*/SKILL.md` (seven with `metadata.version` bumps — `api-auth`, `api-errors`, `api-services`, `api-telemetry`, `field-test`, `report-issue-local`, `tool-defs-analysis`, plus `git-wrapup` and `orchestrations`) and 6 `scripts/` (new `check-dependency-specifiers.ts`; `devcheck.ts`, `lint-packaging.ts`, `build-changelog.ts`, `check-framework-antipatterns.ts`, `check-skill-versions.ts`).

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.10.6 → ^0.10.9
- `@types/node` ^25.9.3 → ^26.0.0
