# 0.1.14 — 2026-06-15

## Added

- **`createApp()` `instructions`** — server-level usage guidance for clients: when to reach for `earthquake_get_feed` (USGS real-time magnitude tiers) vs `earthquake_search` (historical/filtered, sized with `earthquake_count`, 20,000-event cap), how network-specific event IDs flow into `earthquake_get_event`, and that `source=emsc` uses the independent European-Mediterranean catalog and ignores USGS-only filters.

## Changed

- **Plugin identity** — `.claude-plugin/plugin.json` (`name`, `mcpServers` key), `.codex-plugin/plugin.json` (`name`, `interface.displayName`), and `.codex-plugin/mcp.json` (server key) now use the unscoped `earthquake-mcp-server` so the displayed agent-facing identity is the hyphenated repo name rather than the npm scope. Install `args` stay `@cyanheads/earthquake-mcp-server` — the published npm package name is unchanged.
